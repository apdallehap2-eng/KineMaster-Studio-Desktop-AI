KineMaster Studio v8.1.15 AI - إعداد بناء مُثبّت Windows 7 (32-bit)
====================================================================

محتويات الحزمة
--------------
- index.html و index1.html: صفحات الواجهة الأصلية الموجودة في الأرشيف.
- main.js: نقطة تشغيل Electron الأصلية.
- package.json: إعداد بناء معدّل إلى Electron 22.3.27 و electron-builder 23.6.0.
- BUILD.bat: تثبيت المتطلبات وإنشاء ملف Setup EXE.
- START.bat: تشغيل نسخة المصدر أثناء التطوير.

مهم قبل البناء
--------------
1. هذه الحزمة تُجهّز عملية البناء، لكنها ليست ملف EXE مثبتًا بالفعل.
2. استهدفنا Windows 7 32-bit باستخدام Electron 22.3.27 و ia32؛ لا يمكن ضمان عمل كل الوظائف قبل اختبار التطبيق على الجهاز المستهدف.
3. على Windows 7، استخدم Node.js 16.20.2 إصدار Windows x86 (32-bit) مع npm. إصدارات Node الأحدث قد لا تعمل على Windows 7.
4. يحتاج البناء إلى اتصال بالإنترنت لتنزيل حزم npm وملفات Electron وموارد NSIS.
5. فك ضغط المجلد إلى مسار بسيط مثل C:\KineMasterBuild، ثم انقر مرتين على BUILD.bat وانتظر حتى ينتهي.
6. عند النجاح، ستجد ملف التثبيت داخل مجلد dist باسم قريب من:
   KineMaster-Studio-AI-Setup-8.1.15-Win32.exe
7. انقل ملف EXE الناتج إلى جهاز Windows 7 للتثبيت والاختبار.

ملاحظات فنية
------------
- package.json الأصلي طلب Electron ^28.0.0، وهذا غير مناسب لهدف Windows 7.
- تم تثبيت إصدار Electron على 22.3.27 بدل نطاق إصدارات مفتوح، وتحديد معمارية ia32.
- لم يتم حذف index1.html؛ تم تضمين الملفين الأصليين كما وُجدا.
- المشروع الأصلي صغير ويحمّل index.html محليًا. لم أضف وظائف تحرير فيديو جديدة أو أختبر وظائف غير ظاهرة في الملفات.
- إذا فشل npm install بسبب شهادات TLS أو عدم دعم الشبكة في Windows 7، أنشئ المُثبّت على جهاز Windows أحدث باستخدام Node.js متوافق مع أدوات البناء، ثم اختبر الناتج على Windows 7. لا تغيّر معمارية الهدف عن ia32.
